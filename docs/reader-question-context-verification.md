# 论文选段提问上下文

2026-10-14，日常修改和阶段性验证；未生成安装器或更新已安装应用。

使用方式：在 PDF 中划选词语或段落，点击“添加到提问上下文”。可以连续添加
多个选段；同一文字和页码的重复选段会复用已有引用。原有自动划选翻译保留。
跨页选区保留全部页码；拼接模式也可“合并添加上下文”。添加后输入框获得焦点。

右侧提问框展示引用原文、页码，以及移除和清空操作。长段落可展开全文，列表
高度受限，保留输入框可用空间。成功发送后引用保留，便于继续就同一组原文
提问；提交失败保留问题和引用。连续提交受到保护，不会重复创建问题任务。
关闭右侧面板或切换全文翻译不丢失当前问题草稿和引用。草稿属于当前论文阅读
会话；问答卡片则持久保存当次引用快照，重试使用该快照，独立于当前草稿。

上下文经过共享验证：最多 20 段、20,000 字符、1,000 个定位矩形；检查页码、
ID 和规范化坐标，不静默截断。问题仍单独传递并保留原有 4,000 字符限制。
主进程与 preload 通过独立参数传递引用，模型提示要求优先核对引用所在页及
前后文，结合多个选段回答。引用标为不可信资料和定位线索，不能直接充当已
核验证据；原有 `paper_save_answer` 的逐页引文核验继续生效。

`paper_artifacts.question_contexts_json` 保存引用快照，数据库版本升级为 12。
旧版数据库升级前自动备份；旧任务和无选段的问题默认使用空引用列表。
