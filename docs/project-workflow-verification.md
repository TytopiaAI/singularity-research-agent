# 研究项目全流程

研究项目统一关联论文材料、方法版本、实验说明、讨论记录、科研发现与稿件。原有项目默认从方法确立阶段开始；阶段与记录保存在 research.sqlite 的新增表，不改写旧论文或稿件。

- 方法确立：项目推荐与领域总结带入共同研究问题、当前方法和近期实验反馈；下载或复用库内论文后关联项目。方法迭代保存为新版本，讨论可手动记录，也可在语音对话记录中连同引用来源保存。
- 实验：每次实验绑定方法版本，保存目的、数据划分、配置与基线、参考命令、状态、结果、结论和下一步。历史实验不能替换方法归属；方法修改时创建新实验。记录中的命令不自动执行，可复制说明并进入首页助手，选择实际工作区后运行。
- 写作：进入项目已有稿件，首次进入则创建并关联稿件。段落生成和论证检查带入当前方法与近期实验记录；可返回项目补证据，返回前保存段落。
- 阶段允许回退和跨阶段查看，调整说明保留在历史中。项目可标记完成、重新打开；研究记录不会因此删除。

上下文摘要最多包含当前方法、近期三次实验和讨论，较长记录做摘要截取；完整记录保存在项目内。实验摘要附方法版本与名称，避免把旧实验结果归到新方法上。模型提示区分用户研究记录、论文事实和待验证建议，不允许编造未运行实验的结果。

验证：新增数据库测试检查阶段回退、旧版本冻结、重启后保留、跨项目拒绝、重复打开稿件、完成/恢复。界面测试检查项目推荐归属、复用已有论文的关联操作、讨论与引用来源保存。scripts/verify-project-workflow.cjs 使用隔离数据检查真实界面的方法 v1 → 实验反馈 → 方法 v2 → 科研发现 → 关联稿件，并生成截图；不调用模型或实际运行研究实验。
