## 修改

- 单栏中的公式碎片、编号不再作为双栏证据。真正的双栏按左右列阅读，跨列标题保留在对应章节之前。
- 将分式、多行公式、上下标碎片与右侧编号按几何位置合为完整公式区域，使用 PDF 原文裁切显示，不交给模型翻译。正文中的行内等式仍正常翻译。
- 提取引用上标与数学上下标，翻译前替换为受保护标记；结果必须完整保留这些标记，之后还原。使用 React 的 `sup`、`sub` 节点显示，其他 HTML 不作为可执行内容渲染。
- 排版版本升级为 2。首次打开旧缓存会重新提取布局，按原文、类型、范围和页码复用已有译文，并保留 `.layout-1.bak` 完整备份。已被展开成普通数字、无法安全还原的引用上标仅使对应段落待补全，点击“继续翻译”处理。迁移本身不发起模型请求。
- 总结、笔记、问答卡片使用更接近白色的浅色背景，保留边缘区分色；深色主题使用轻微色调并保持文字对比。全文翻译卡片也减淡底色。
- 清理阅读卡片的延迟聚焦计时器，避免退出阅读界面后继续访问已卸载的页面。
