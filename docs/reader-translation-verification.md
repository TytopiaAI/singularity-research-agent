# 论文阅读与翻译阶段验证（2026-10-09）

本轮只修改源码、运行回归验证与开发构建，没有生成或安装 Windows 安装包。

## 阅读行为

- 阅读器标题栏与 PDF 工具栏固定占据布局空间，长文滚动和出现选区工具时不再压缩顶部栏。
- 选择工具下，鼠标划选文字会自动生成右侧翻译卡片；重复选择已有译文会复用卡片。
- 移除所有段落的常驻下划线，保留原生文字选区和当前选段的浅色定位。
- 工具栏的链条按钮开启拼接模式。依次划选各页片段，在右侧预览、校正原文，再点击“合并翻译”；支持撤销上一段。
- 单次连续跨页拖选也受支持。仅提取 PDF 文字层，排除页码标签和容器矩形，各页的坐标保存到卡片中。
- 点击“全文翻译”开始正文翻译；识别到 Appendix、Appendices 或 Supplementary Material 等附录标题时，右侧显示单独的附录选项。正文与附录分别生成、分别复用。
- 左侧 PDF 与右侧逐段原文／译文独立滚动，中间分隔条支持拖动或方向键调整比例。
- 独立公式用原 PDF 区域显示，不发送给翻译模型；正文的行内符号保留。识别到可定位的嵌入图像时保留原图，图注参与翻译。

## 本地保存

全文结果写入 `artifacts/<paperId>/translation-v1-<PDF checksum>.json`，与具体 PDF 内容绑定。每批结果校验段落 ID、完整性、重复项和非空译文，通过后原子写入文件。已完成部分在重新打开时直接读取；失败或应用退出中断后，可继续剩余部分。后台翻译在关闭阅读面板后继续，退出应用则停止。

数据库迁移到版本 11，新增阅读卡片跨页坐标列。升级前备份原数据库，旧卡片保持兼容。
