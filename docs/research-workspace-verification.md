## 仍需真实使用验收的边界

- 未调用真实付费模型，不能以模拟测试替代新闻质量、论文推荐质量或翻译准确性的验收。
- 125%/150% 检查使用 Electron 页面缩放，未更改 Windows 显示器系统 DPI；多显示器跨 DPI 移动尚未验证。
- 测试 PDF 是单页文字夹具，多栏、旋转页面、超大 PDF 和扫描件还需要更多样本验证。
- 未实际填满磁盘模拟空间不足；导入错误会保留原文件并按文件报告失败。
- 本轮保留 Harness 全文翻译入口，但不声称已经验证逐块自动续跑；论文早报当前标注为摘要级解读。
- 关闭时不保留后台进程，不运行 Windows 计划任务。
