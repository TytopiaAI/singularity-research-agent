# 科研发现：论文推荐与领域总结

入口位于科研发现顶部。论文推荐支持 1–3 个预设或自定义核心方向，目标 5 篇；领域总结支持独立的核心领域和思路来源（各最多 3 项），论文总数可选 5/10/15/20 篇。发表时间可选近 1/2 年，预印本可选近 4/6 个月。

流程：关键词规划 → 多源检索 → 来源与日期核验 → 去重/选稿 → 原文阅读 → 方法、数据集、基准与贡献分析 → 2–3 条研究启示。任务、阶段结果、来源与历史保存在应用自己的数据库；可取消，重启后的中断任务保留结果并提示重试。

来源策略：arXiv API 失败时使用公开搜索页；正式论文来自 OpenAlex 出版记录或 Crossref DOI 登记元数据，覆盖不足时按正式发表场所补搜。会议名称只能从正式来源字段判断，不能从论文标题猜测；预印本单独分组，不能仅凭作者 comments 宣称已录用。原文优先读取 arXiv PDF，必要时尝试 HTML 正文；无法取得正文时标为仅摘要，贡献程度降为待核验。模型提交的引句必须真实出现在采集文本中。作者仓库链接只从原文提取，读取公开 README 而不运行代码。检索不足时显示缺口，不放宽时间范围或编造论文凑数。

入库：仅由推荐记录解析已知 arXiv ID；缺少 ID 时按完整标题查找一致版本。验证 PDF 头后使用现有论文库导入流程复制到本机托管目录，按校验值去重。缓存已下载的 PDF，并持久化入库状态；不从模型输出中接收任意下载地址。

领域综述与论文推荐的评分原则参考公开的论文推荐技能说明。保留其多源检索、去重、深读和研究启示原则，调整如下：

- 固定年份/时刻改为滚动时间窗口和手动入口；不创建定时推送或向外部发送消息。
- 原有 Linux/Hermes 路径和 UR.xlsx 去重改为应用论文库与本地推荐历史。
- 完整标题与 ID 去重，不截断前 80 字，避免长标题误判；领域总结允许重访重要已读论文，已有论文显示入库状态。
- 摘要不能代替全文；不以会议缩写、机构声望、摘要长度、关键词计分来证明突破或最先进。
- 不默认排除数据集和 benchmark，纳入评估变化、泄漏风险和复现条件。
- 日期精度按来源保留，月/年级元数据只有在整个日期区间都落入窗口时才收录。

阶段验证使用独立数据。单元测试覆盖日期、正式发表分类、撤回过滤、完整标题去重、引句真实性、分组、持久化、取消、源绑定下载和导入状态。真实 Chromium 验证配置、五张简易卡片、两组论文、展开信息、入库反馈、取消及 100%/125%/150% 布局。公共检索源连通及真实候选收集另行验证；实际模型研究质量未使用用户凭据实测。

最终验证：19 个测试文件，103 项测试通过；类型检查及开发构建通过。实际公开 arXiv PDF（2610.12244，26 页）已验证下载、解析、独立托管论文库导入、重复导入复用和状态保存。完整应用的五种背景在各页面同步切换验证通过。没有打包安装。

参考接口文档：[arXiv API](https://info.arxiv.org/help/api/user-manual.html)、[OpenAlex 筛选](https://help.openalex.org/api/filtering/)、[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)。
