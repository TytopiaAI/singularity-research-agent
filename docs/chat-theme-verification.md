# 聊天背景切换阶段验证（2026-10-09）

本轮只修改与构建开发产物，没有打包、安装或调用模型。

## 原因与修复

聊天背景选择器运行在 Electron 的隔离预加载环境中。旧代码在 `focusout` 事件的微任务里检查 `document.activeElement`，但鼠标从当前颜色点击另一个颜色时，该检查可能发生在旧按钮失焦与新按钮获得焦点之间。此时 `activeElement` 暂时是 BODY，面板因此提前关闭，鼠标松开时目标选项已经隐藏，无法产生有效点击。

改为使用 `FocusEvent.relatedTarget` 判断焦点即将转移到的元素。颜色之间转移焦点时保留面板；焦点移出选择器、点击外部或按 Escape 时继续关闭。

## 验证

- 原先使用 DOM `.click()` 的界面检查会通过，不能复现真实鼠标问题。
- 已将 `scripts/verify-chat-theme.cjs` 的颜色切换改为 Electron `sendInputEvent` 的真实鼠标移动、按下、松开事件。
