# 领域知识库与统一滚动条 · 2026-10-15

在“科研发现”点击“领域知识库”。既有论文推荐、领域总结中已完成分析的论文会补入核心领域；新检索默认按核心主题自动积累，也可以在检索设置中选择已有知识库，把更具体的子方向统一收入大领域。从某个知识库点击“继续查找论文”会自动选中该领域。

领域数据跨多次检索保存，按 arXiv ID（忽略版本后缀）或规范化完整标题去重。纯思路来源论文标为跨领域思路。根据核心机制自动归类，支持 1–3 个方向及手动修改；已手动维护的归类不被后续检索覆盖，已有原文分析也不会被摘要级结果降级。历史补入覆盖所有已保存研究任务，不限历史下拉框的最近 50 项，并避免重启时反复以旧分析覆盖新结果。

图谱纵轴是研究方向，横轴是发表月份或年份；同方向论文按时间连线，同月/年内的多篇论文分层放置。虚线只表达时间先后，实线表达用户维护的方法改进、机制结合或思路借鉴；关系必须有说明，同领域校验及时间方向校验避免无效连线。可以筛选方向、缩放、滚动和点击节点查看具体方法、数据、评估、原文级别、风险与启发，并使用现有 arXiv 下载/入库流程或加入当前项目。

每个领域维护一个本地 Markdown 文档，位于当前数据目录的 `artifacts/fields/<领域 ID>/knowledge.md`。论文、方向、关系、个人笔记变化时自动写入结构化资料。成功完成新检索后更新综合综述；也可手动更新。综述含发展脉络、评估可比性及 2–3 条研究启发，每节引用必须来自收录论文。综述来源是已有论文分析，不宣称重新阅读全文或已经核验全部机制关系。个人笔记独立保存，综述不会覆盖；保存笔记有并发修改校验。

界面区分“待生成 / 与当前资料一致 / 新资料待更新 / 更新中 / 失败待重试”。失败保留上一次有效综述和全部结构化资料；更新期间新增论文不会被旧快照覆盖。图谱单次最多显示 100 篇，可按方向缩小范围；文档和数据库保留全部论文。一次综合综述最多取 60 篇（较早 20 篇和最新 40 篇），界面明确显示覆盖篇数；全部方向时间线与逐篇分析不受此限制，不把有限覆盖称作完整领域史。自动综述使用当前模型配置；历史迁移本身不调用模型。

React 页面和独立原生聊天视图共享滚动条规则：9px 轨道、圆角细滑块、透明背景、悬停反馈，适配明暗主题及高对比模式。
